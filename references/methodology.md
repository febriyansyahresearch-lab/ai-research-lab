## Methodology Notes

The projects in this repository follow a consistent research methodology:
1. Problem formulation aligned with real cybersecurity challenges
2. Synthetic data generation for controlled experimentation
3. Baseline model implementation from scratch (where feasible)
4. Evaluation using standard metrics (precision, recall, accuracy)
5. Reproducible pipeline design
