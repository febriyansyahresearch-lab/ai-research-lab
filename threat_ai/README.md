# Threat AI

AI for threat intelligence — attack graph analysis, inference engine, IOC correlation.

## Approach
- Attack path analysis using graph search (BFS/DFS/A*)
- Threat inference engine with rule-based reasoning
- IOC (Indicator of Compromise) correlation and scoring
